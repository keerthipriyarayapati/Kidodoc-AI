# KidoDoc AI — Pediatric Healthcare Assistant

KidoDoc AI is a full-stack AI-powered pediatric healthcare web application designed to assist in symptom-based disease prediction and child healthcare monitoring.

The application integrates Machine Learning, Flask backend services, MongoDB database management, and a modern React.js frontend to provide an interactive healthcare experience.

---

# Features

* AI-powered symptom-based disease prediction
* Pediatric healthcare dashboard
* Child health management modules
* Prediction history tracking
* Downloadable PDF medical report generation
* Responsive modern healthcare UI
* MongoDB database integration
* REST API communication using Axios

# Installation

## Clone Repository

```bash
git clone https://github.com/keerthipriyarayapati/Kidodoc-AI.git
```

---

# Backend Setup

```bash
cd backend
python -m pip install -r requirements.txt
python app.py
```

Backend runs on:

```bash
http://127.0.0.1:5000
```

---

# Frontend Setup

```bash
cd frontend
npm install
npm start
```

Frontend runs on:

```bash
http://localhost:3000
```
